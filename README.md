# Black Clover


GitHub Repository Context: https://github.com/evnr7022-a11y/Evn_Anime

Requirements & Features:

1. Design Aesthetics:

   - Ultra-dark, charcoal & glassmorphism aesthetic (#0F171D background).

   - Inspired by Asta's 5-Leaf Clover Grimoire and the Black Bulls insignia.

2. Main Landing Page (Home Page):

   - Hero Banner featuring Asta & Yuno with a "Start Watching / ابدأ المشاهدة" button that smoothly scrolls or navigates to the episode player.

   - Story Arcs Navigation (الأركات): Interactive cards to filter or skip directly to specific story arcs:

     * Entrance & Magic Knights Exam (Ep 1–13)

     * Seabed Temple Arc (Ep 40–50)

     * Elf Reincarnation Arc (Ep 90–120)

     * Heart Kingdom & Spade Kingdom Arc (Ep 158–170)

   - Quick Highlights / Top Battles Section (أقوى القتالات): Direct links to fan-favorite fights.

   - Grimoire / Characters Showcase (الموسوعة): Minimalist cards for main characters (Asta, Yuno, Yami, Noelle).

3. Episode Player & List Page:

   - Full integrated streaming player with custom media controls.

   - Sidebar/Grid listing all 170 episodes sequentially (from Episode 1 to 170).

   - Episode search bar & filter by arc.

Ensure the UI is responsive, bilingual-ready (Arabic/English), and uses smooth transitions.
